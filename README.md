# FadeYin 拉片日记

面向电影学习与逐镜分析的本地拉片工具。导入视频，检测镜头切点，浏览中间帧，按场次整理并填写拉片笔记。

当前版本：**0.6.1 预览版**。开发者：Danny。

**AI 功能暂未上线。** AI 按钮保持灰色，提示「功能未上线，敬请稍后」；当前版本不支持填写 API Key 或调用 AI 分析。

## 功能

- 桌面版通过 FFmpeg 检测切点，提取每个镜头的中间帧。
- 手动添加切点、合并镜头，播放对应镜头。
- 手动分场或建立序列，每场有标题、封面与独立标签页。
- 填写景别、角度、运镜、光色、画面内容、声音和备注；支持常用下拉项与自定义输入。
- 拖动分析列表表头调整顺序，拖动列边缘调整宽度。
- 左侧项目库保存镜头、分场与笔记，方便继续拉片。
- 全片通览：亮度、色彩条码、剪辑密度；音频电平需桌面版。
- 导出包含视频和笔记的单文件 HTML，或导出飞书兼容 CSV。

## 开始使用

### HTML 版

下载本仓库后，用桌面 Chrome 或 Edge 打开 `outputs/FadeYin拉片日记.html`。无需安装依赖。可播放格式取决于浏览器支持，优先使用 H.264 MP4。

HTML 版在浏览器中采样检测；桌面版使用 FFmpeg，检测实现不同。HTML 版不能直接调用本机 FFmpeg。手机更适合查看导出的报告，编辑界面目前仍有窄屏适配问题。

### Windows 桌面版

若下载了 Windows 便携 EXE，双击运行即可。安装包与源码分开管理，仓库中的「Download ZIP」是源码，不等于可执行安装包。本仓库未附带 EXE，不要假定已有 Releases 下载页。

### 从源码启动桌面版

需要 Node.js 与 npm。在仓库根目录打开终端：

```sh
cd desktop
npm ci
npm start
```

首次安装需要联网下载 Electron、FFmpeg 等依赖。不要把 Windows 的 `node_modules` 复制到 Mac 使用。

## 拉片步骤

1. 点击「选择视频」，或把视频拖入窗口。
2. 设置检测灵敏度和最短镜头帧数。桌面版读取原片帧率；HTML 版请手动核对帧率。
3. 点击「自动检测切点」。进入「拉片模式」本身不会启动检测。
4. 检查镜头边界。选择工具可点击镜头，Shift 点击可连续多选；刀片工具用于手动添加切点。快捷键 V 为选择工具，B 为刀片工具。
5. 选中连续镜头后点击「选中镜头分场」或「建立序列」，填写标题和范围。分场不会自动生成，当前不支持场次范围重叠。
6. 在场次标签页填写景别、角度、运镜、光色、画面内容、声音和备注。分场封面默认取场次时间中间帧，也可用「当前画面设为封面」更换。
7. 使用「导出拉片日记」生成 HTML 备份。导出时请等待完成再切换项目。

## 保存与恢复

项目自动保存在当前浏览器或应用的本机存储中，**不是云端同步，也不会复制原视频**。请保留原视频；HTML 版恢复项目时可能需要重新选择相同文件。

更换浏览器、清除站点数据或改变网页地址可能使原项目无法访问。导出 HTML 是阅读与分享文件，当前没有把导出日记重新导入为可编辑项目的入口，不能替代完整可编辑项目备份。

## 导出说明

| 导出方式 | 内容与限制 |
| --- | --- |
| 拉片日记 HTML | 内嵌原视频、镜头图片、笔记和场次标签；文件较大，手机是否能打开取决于浏览器、编码和可用内存。 |
| 镜头报告 HTML | 内嵌原视频和镜头卡片，可点击播放镜头。 |
| 桌面 MP4 | 通过 FFmpeg 重新编码导出镜头片段，保留画面分辨率；不是无损复制。每次请选新的导出文件夹。 |
| HTML 版 ZIP | 在浏览器中实时录制 WebM 片段，耗时接近视频时长。 |
| 飞书兼容 CSV | 导出文字表格并打开飞书，仍需手动上传导入；不包含图片、视频附件，不是自动同步。 |

如需片段导出，建议在检测前勾选对应选项；当前版本检测后勾选可能无法立即显示导出按钮。

## 已知问题

本版本不应作为唯一笔记存储位置。已确认的问题详见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)，包括重新分析后笔记错配、快速连续合并丢笔记、导出时切换项目造成内容混合、重复导出覆盖文件，以及短镜头漏检和播放越界。

建议先确定镜头边界再填写笔记，每次编辑等待缩略图刷新；导出期间不要切换影片或重复点击。重要资料请额外保存文字副本。

## 构建

在 `desktop` 目录执行：

```sh
npm run check
npm run build:win
```

Mac 构建命令为 `npm run build:mac:x64` 或 `npm run build:mac:arm64`，应在对应 Mac 环境安装依赖并构建。**macOS 尚未完成实机验证、签名和公证**，不能将构建配置视为兼容性保证。

## 数据与依赖

影片分析与笔记保存在本机。导出的单文件 HTML 包含原视频，分享该文件也会分享其中的视频内容。飞书按钮会打开外部网站。

仓库只包含应用源码、图标和文档，不包含影片、私人笔记、缓存或第三方二进制。第三方依赖分别遵循自己的许可证；向公众分发包含 FFmpeg 的安装包前，应完成对应构建的许可证及源码提供要求核对。当前项目未声明开放源码授权（`UNLICENSED`），上传 GitHub 不自动授予他人使用许可。
