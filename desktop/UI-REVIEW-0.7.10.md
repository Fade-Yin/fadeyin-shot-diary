# 0.7.10 界面对抗式审查与清理

证据：用户截图、当前源码、独立只读审查、DOM/状态替身回归及静态检测。未进行真实窗口渲染验收；不能据此宣称全界面视觉/无障碍验收通过。

## 已处理

- 删除“FFmpeg 分析”非交互标签，避免看起来像不可点击按钮。
- 产品名只保留系统标题栏；左侧改为“项目库”，隐藏主工作区与拉片表格中的重复产品标题。
- 隐藏重复的列拖动说明、时间线操作说明、序列筛选说明、导出报告解释；保留真正的操作按钮、序列标签、统计、时间码与错误提示。
- 导入视频后的上传图标与重复状态说明不再占用空间。入口保留，仍可拖入和选择视频。
- 当前项目封面保存检查 localStorage 返回值与持久化状态，避免失败后提示成功。
- 被拒绝的重复加载不再使正在生成的默认封面任务失效。
- 项目迁移失败增加主动错误提示，避免重要错误藏在设置内。

## 保留的必要内容

图标按钮的悬停名称与无障碍标签、未上线 AI 状态、序列范围/错误、项目保存失败、处理中/取消、导出位置和帧位选择均保留。

## 剩余验证边界

Windows 实际窗口尺寸、系统缩放、鼠标图标效果、窄面板重排，以及 macOS 未实测。变帧率视频的第24帧/逐帧定位仍以帧率计算，并非真实帧时间戳索引。
