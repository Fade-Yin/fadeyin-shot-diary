# 0.9.3 悬停播放

- 分析模式与拉片模式：鼠标进入镜头画面，自动从该镜头保留的位置播放；鼠标离开即暂停。
- 小镜头画面实时播放，离开后冻结；对应帧进度条保留暂停位置。
- 再次进入继续播放；已经到达结尾的镜头再次进入从开头播放。
- 移除镜头播放按钮及旧鼠标横向定位入口，保留进度条手动定位和合并、切分按钮。
- 快速切换时只有当前镜头拥有播放器，页面失焦或卡片被替换时停止预览。

验证：真实视频在本地浏览器的分析、拉片模式播放与离开暂停；暂停一分钟后时间未变化；再次进入续播；无相关页面控制台错误。事件测试验证不点击直接移入、进度保留、快速切换与动画帧清理。尚未在打包 EXE 窗口内完成完整鼠标交互回归。
