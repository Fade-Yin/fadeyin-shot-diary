# 片拉拉工作台 · 0.9 Tahoe

0.9 按 macOS 26（Tahoe）的 Liquid Glass 设计语言重做表现层与导航。实现位于 `ui/tahoe.css` 与 `ui/tahoe.js`，在 `mac-workbench.js` 之后加载；所有命令都代理已有按钮，不修改项目、编辑、导出引擎或已保存的数据与布局。

## 材质与层级

- 玻璃材质只用于导航和浮层：工具栏按钮组、搜索栏、项目边栏、弹窗、命令面板、右键菜单、HUD 提示。内容（播放器、镜头、表格）保持不透明，柔和阴影抬升，不加边框。
- 玻璃：`saturate(180%) blur(28px)`，顶部 0.5px 高光、0.5px 外描边。macOS 窗口启用系统 `under-window` vibrancy，窗口底色半透明。
- 「减少透明度」时玻璃退回不透明表面；「减少动态效果」时关闭过渡与动画。

## 视觉系统

- 浅色：窗口 #ececf0、内容 #ffffff、标签 #1d1d1f、次级 60% / 三级 45% 透明灰、强调 #0a7cff。
- 深色：窗口 #141416、内容 #1f1f22、标签 #f5f5f7、强调 #3d9bff。危险操作 #ff3b30。
- 填充色使用半透明系统灰（`--t-fill`），共享变量 `--surface-input`/`--hover` 保持不透明，避免叠在深色区域时失真。
- 圆角同心：面板 18px、按钮 10px、浮层 22–24px、菜单 14px；主要操作、标签、分段控件为胶囊形。
- 字体：SF Pro / 苹方；时间码使用等宽数字（tabular-nums），不使用等宽字体。
- 图标：SF Symbols 风格，24 网格、1.6 描边、圆角端点，播放类为实心图形；由 `tahoe.js` 按按钮的 `data-icon-key` 换绘，状态切换（播放⇄暂停、静音）自动跟随。

## 操作逻辑

- 工具栏：边栏开关 · 应用标题与保存状态 · 搜索栏 · 图标按钮组（备注、布局、快捷键、设置）· 导出。
- 命令面板 ⌘K / Ctrl+K：项目、镜头编号跳转与全部常用命令，↑↓ 选择、回车执行、Esc 关闭。
- 镜头右键菜单：跳到镜头 + 卡片自带操作（合并、切分、播放），方向键导航。
- 边栏 ⌃⌘S / Ctrl+Alt+S 显示或隐藏并记住；⌘O / Ctrl+O 打开视频。原有 J/K/L、空格、C、V、B 快捷键不变。
- 分段控件使用滑动选中块；提示为底部居中 HUD；全屏预览时播放控制浮于画面之上。

## 图标

应用图标源文件为 `assets/icon-source.svg`。修改后运行 `node scripts/build-icons.cjs`（Linux 无显示器时用 `xvfb-run`），生成 `fadeyin-icon.png/.ico/.icns` 与 `ui/app-icon.png`。

## 验证

`node scripts/screenshot-ui.cjs <输出目录> [视频]` 用 Playwright 启动 Electron，截取浅深色、三种模式、命令面板与右键菜单。截图在 Linux 下渲染，macOS 实机的 vibrancy 与交通灯位置仍需在 Mac 上确认。

# 片拉拉工作台 · 0.7.5

本次是既有编辑界面的统一与精修，不替换产品标识、业务逻辑、用户数据或已保存的停靠布局。

使用场景：桌面上长时间观看影片、拆镜头、标记序列并填写拉片笔记。模式为 Operate，播放器和素材内容优先于界面装饰。

## 视觉系统

- 深色：石墨底色 #18191b、面板 #202123、正文 #eeeae3、次级文本 #b0aaa1、香槟强调 #d2bfa2。
- 浅色：暖灰底色 #efeeeb、面板 #faf9f7、正文 #272624、次级文本 #69655f、深棕强调 #695540。
- 强调用于选择、焦点和主要动作；危险操作保留独立红色。
- 系统中文字体用于操作型桌面界面；12–13px 正文、11px 辅助文字、20px 产品标题。时间码采用等宽数字，不采用装饰性等宽字体。
- 4px 空间基础节奏，按钮默认34px，触控44px，控制圆角6px，面板10–12px。
- 使用边框表达面板层级，不增加玻璃效果、渐变、装饰性阴影。弹窗和提示使用同一主题。

## 层级与操作

顶部保留模式切换、键盘提示与齿轮。未上线 AI 入口保留灰色，移至全局设置。截图保留在播放器工具栏。

项目库紧凑排列，删除叉号仍仅在悬停或键盘焦点时出现；封面仅使用已有列表数据，不为视觉目的额外读取整部影片。

镜头分析自适应缩略图网格；播放、合并和定位条保持可见，键盘与触控用户无需依赖悬停。拉片表格保留用户列顺序、列宽和自动保存。

设置增加紧凑/舒适密度，可独立保存，不修改任何拉片内容。

## 验证边界

代码、状态回归、静帧真实 FFmpeg 测试及打包资源可验证。当前环境的历史浏览器安全限制使真实窗口渲染与截图验收不可执行，因此不得把源代码审查宣称为视觉验收通过。变帧率逐帧定位、macOS 与真机窄屏仍需后续验证。
