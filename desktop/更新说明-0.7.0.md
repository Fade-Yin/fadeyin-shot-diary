# 片拉拉 0.7.0 · 本地开发版

## 改动

- 软件显示名称改为片拉拉；开发者 Danny。内部 app.name、项目数据库键、UI 文件路径和 IPC 名称保留，以兼容旧项目，而非清空重建。
- 检测设置下增加「静帧导出」：选择起始帧或中间帧后，一键按全片每个镜头导出一张原尺寸 PNG。直接从视频解码，不使用低分辨率缩略图。每次新建独立目录，支持取消与打开导出文件夹。
- 统一「序列分析」：移除独立分场入口及类型选择。旧场次以原 ID、标题和笔记保留，统一为序列。
- 选择连续镜头（Shift 连选）→ 建立序列；可修改标题及起止镜头、查看范围时码、拆分、合并相邻序列、移除序列。重叠范围不允许保存；移除需确认且不删除镜头/笔记。支持撤销/重做。
- 序列标签同时筛选拉片表与镜头缩略图。未归入序列的镜头仍可在「未归入序列」标签查看；不自动分组。
- 拉片模式的全片通览新增景别、角度、运镜。时间条按镜头时长显示标注分布，下方可按镜头数或时长查看占比，包含未填写及自定义项。始终统计全片，不随序列标签缩小统计范围。

## 使用

先导入视频并检测镜头；「静帧导出」位于检测设置下方。

建立序列：选择工具下，点击起始镜头，再 Shift 点击结束镜头；点击「选中镜头建立序列」（S 或 Shift+S），输入标题并确认。点序列后可「修改范围」。旧项目无需重做分析。

填写分布：切换拉片模式，填写景别、角度、运镜，点击通览中相应维度；统计随输入更新。不同自定义完整文字分别计数，不把一段描述自动识别成多个分类。
