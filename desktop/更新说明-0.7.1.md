# 片拉拉 0.7.1

- 界面署名改为「开发者 Fadeyin」。
- 页面左上角图标由内嵌 64×64 PNG 改用原有 1024×1024 图源，不重绘、不改变设计。Windows ICO 经检查已含 16 至 256 等多档尺寸，保持原件。实际不同 DPI 下的视觉清晰度仍需实机确认。
- Windows 点击窗口关闭按钮：同主题弹窗选择取消、最小化到右下角托盘或退出程序。托盘单击/双击恢复窗口，右键可打开程序或再次进入退出确认。
- 分析、导出、项目加载过程中允许退到托盘；禁止直接退出，避免丢失任务或未完成的数据。退出前等待项目保存；保存失败时留在程序内并提示备份。
- 已做关闭状态机/安全 IPC 模拟回归、图标资源尺寸检查及已有功能回归，尚未进行原生托盘和弹窗的实机点击验收。没有绕过此前的页面自动化安全限制。
- Windows 便携版未签名；没有更新 GitHub、旧迁移包或 Mac 安装包。
