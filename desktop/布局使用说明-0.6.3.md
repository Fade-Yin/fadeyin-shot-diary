# FadeYin 拉片日记 0.6.3

## 调整工作区

- 拖动面板上方带「⠿」的标题栏，到另一个面板的左、右、上、下边缘，看到停靠提示后松开。
- 拖到另一个面板中央可交换位置。
- 拖动面板之间的分隔线调整宽高；分隔线也可以通过 Tab 聚焦后用方向键调整。
- 布局自动保存在本机。右上角「恢复布局」可恢复默认布局。
- 当前支持播放器、检测设置、时间线与镜头工作区三个面板的窗口内停靠，不支持独立浮动窗口或跨显示器停靠。

## 缩略图浏览

镜头分析模式使用自动换行的缩略图网格。在「分镜结果」标题旁，使用减号、加号或滑块改变缩略图大小。每行数量随可用宽度自动调整，原来的播放、合并、重新分析及导出按钮保留。

拉片模式仍保留可编辑表格。窄屏自动使用纵向布局。

Windows 便携版内置 FFmpeg / FFprobe，无需另外安装。AI 功能保持未上线。本版本未做发布者代码签名。
